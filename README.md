## 🚀 Deployment to Vercel

### Option 1: Standard React / Vite Deployment
1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import the GitHub repository.
4. Framework Preset: **Vite** (detected automatically).
5. Click **Deploy**.

### Option 2: Standalone Static HTML / CSS / JS (Zero-Build)
If you prefer a pure static site without any build step:
- The static files (`index.html`, `style.css`, `script.js`) are ready in the `static/` directory.
- Simply upload the contents of the `static/` folder to any static hosting or drag & drop onto Vercel / Netlify / GitHub Pages.
